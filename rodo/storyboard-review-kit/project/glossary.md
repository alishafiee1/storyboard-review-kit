# واژه‌نامه

> هر واژه همان معنایی را دارد که اینجا نوشته شده؛ در سناریوها و spec همین واژه‌ها به کار می‌روند.

| واژه | معنی | در کد |
|---|---|---|
| پیش‌نویس ۱K | اولین خروجی قابل‌استفادهٔ یک تصویر از Flow، کیفیت پایه، برای بررسی در صفحه | `_1K` یا فایل بدون پسوند کیفیت |
| کیفیت ۲K | همان نسخه با وضوح بالاتر؛ فایل جدا کنار پیش‌نویس، نه جایگزینی با تغییر نام | پسوند `_2K` در `flowname.py` |
| نسخه | یک خروجی Flow برای یک تصویر، با شناسهٔ تصادفی هشت‌هگز | `rid`؛ `pick:` همین را نگه می‌دارد |
| انتخاب‌شده / تأییدشده | نسخه‌ای که کاربر روی آن ایستاده و در سناریو ثبت شده | `pick:` در `story.txt` |
| کهنه | پرامپت یا وضعیت عوض شده و تصویر فعلی دیگر معتبر نیست | `image-stale: yes` |
| پرامپت | بلوک کامل انگلیسی ساخت تصویر در `prompts/prompts.txt` | `[OUTPUT NAME:]`, `[REFS TO ATTACH:]` |
| مرجع | تصویر شخصیت / مکان / وسیله که به پرامپت صحنه وصل می‌شود | `images/refs/`، نام‌هایی مثل `STYLE_ANCHOR` |
| کتابچه | نوع محتوای فعال: داستان یا مرجع‌ها | `book = "story"` یا `"refs"` |
| صحنه | بخش‌بندی کتابچهٔ داستان | `=== scene-01 \| عنوان \| زمان ===` |
| بخش مرجع | بخش‌بندی کتابچهٔ مرجع‌ها | `=== ref-01 \| Characters \| - ===` |
| بلوک | واحد یک تصویر یا آیتم مرجع با سرصفحه و خطوط وابسته | `[IMG001]` یا `[CH_MIMO]` |
| شناسهٔ آیتم | شناسهٔ پایدار تصویر یا مرجع | `IMG045` یا `CH_ALICE` |
| شناسهٔ خط دیالوگ | شناسهٔ پایدار هر خط زیر تصویر تا صدا قطع نشود | `IMG045-1` |
| انتخاب صدا | برداشت صوتی انتخاب‌شده برای یک خط | `voice: fa=<rid>` |
| دسته | گروه‌بندی ۱۰تایی تصاویر برای ارسال گروهی پرامپت | `b01` در `images/scenes/` |
| ناظر دانلود | ابزار کیت که فایل‌های نام‌آشنا را از Downloads به پوشهٔ پروژه می‌برد | `tools/watch.py` |
| وضعیت اجرا | پروندهٔ پیشرفت و هش پرامپت تا اجرای ناتمام از همان‌جا ادامه پیدا کند | `.kit/flow-state.json` |
| اتصال CDP | کنترل Chrome از قبل بازشده از طریق درگاه اشکال‌زدایی، بدون مرورگر جدا | Playwright `connect_over_cdp` |
| مرز موتور | فهرست مجاز فایل‌هایی که `update.py` در پروژهٔ کاربر کپی می‌کند | `ENGINE.txt`؛ `rodo/` عضو آن نیست |
| تاریخچه / برگشت | عکس فوری پیش از ویرایش ساختاری، تا ۳۰ مورد | `.kit/history/` و `.kit/history-refs/` |
| مودال کاغذی | پنجرهٔ گفت‌وگوی سفارشی به‌جای `alert` و `confirm` بومی | `tools/ui/dialogs.js` |
