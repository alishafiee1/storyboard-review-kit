# معماری

## بخش‌ها

| بخش | فناوری | مسیر در مخزن | چرا این انتخاب |
|---|---|---|---|
| صفحهٔ بررسی | HTML/CSS/JS خام، بدون build | `review.html`, `tools/ui/` | یک صفحهٔ استاتیک؛ آفلاین و قابل‌خواندن |
| سرور محلی | Python 3.9+، بدون بستهٔ اجباری | `tools/serve.py`, `tools/api.py` | ویرایش خط‌به‌خط فایل‌ها با قفل فایل |
| هسته و داده | دیکشنری و regex، بدون ORM | `tools/kitcore.py`, `tools/story.py`, `tools/media.py`, `tools/flowname.py` | `story.txt` و `prompts.txt` منبع حقیقت‌اند |
| نسخه و کیفیت Flow | الگوی نام فایل و `rid` | `tools/flowname.py`, `tools/media.py` | `_1K` / `_2K` / `_4K` یک نسخه؛ بهترین نشان داده می‌شود |
| ورود فایل از Downloads | ناظر پوشه | `tools/watch.py` | برش (نه کپی) فایل‌های با نام شناخته‌شده به `images/scenes/` یا `images/refs/` |
| به‌روزرسانی کیت | فهرست سفید | `tools/update.py`, `ENGINE.txt` | فقط فایل‌های ابزار عوض می‌شوند؛ دادهٔ پروژه دست نخورده می‌ماند |
| اتوماسیون Flow (برنامه‌ریزی‌شده) | Playwright CDP، بدون مدل زبانی | `tools/flow_sync.py` (چرخه‌های 001 و 002) | اتصال به Chrome باز کاربر؛ صفر مصرف توکن LLM |

## دادهٔ اصلی

- `scenario/story.txt`: صحنه، گفت‌وگو، گوینده، `pick:` (نسخهٔ انتخاب‌شده)، `image-stale: yes`
- `prompts/prompts.txt`: بلوک‌های کامل؛ ابتدا refs (`STYLE_ANCHOR`, `CH_*`, …) و بعد صحنه‌های `IMG###`، با `[REFS TO ATTACH:]` و `[OUTPUT NAME:]`
- `images/refs/` و `images/scenes/`: فایل تصویر؛ هویت تصویر `IMG045` است و نام فایل هرگز عوض نمی‌شود
- `.kit/`: تاریخچه، ورودها، و (در چرخه‌های Flow) `flow-state.json` برای هش پرامپت و پیشرفت اجرا
- صدا و ویدیو جدا از این دو چرخه می‌مانند

## تست

- واحد: `python -m unittest discover -s tools/tests -p "test_*.py"`
- مرورگر صفحهٔ بررسی: `python tools/tests/run.py` (با Playwright؛ روی کپی موقت پروژه)
- این دو چرخه هنوز دستور تست پذیرش اجرایی ندارند؛ سناریوها در `acceptance.feature` نوشته شده‌اند تا بعد به `rodo test` وصل شوند

## قواعدی که همه باید بدانند

- هیچ فایل تصویری تغییر نام داده نمی‌شود. کیفیت بالاتر فایل جدید با پسوند `_2K` / `_4K` کنار همان `rid` است
- تصویر تأییدشده (`pick:`) یا پرامپت بدون تغییر، دوباره ساخته نمی‌شود
- رازها (کلید API، کوکی، توکن) هرگز داخل `rodo/` یا فایل‌های کامیت‌شده نمی‌آیند
- CLI اتوماسیون Flow هیچ درخواست مدل زبانی نمی‌فرستد
- دانلود اتوماسیون باید مستقیم به پوشهٔ پروژه برود و با `watch.py` رقابت نکند (نه ذخیره در `Downloads`)
