# Technical Spec: 003-sketchbook-redesign

- **R1:** Two-page spread presentation mounts current shot (`.blk.on`) with script on the opposite page.
- **R2:** Typography uses bundled offline `Vazirmatn` woff2 fonts and SVG stroke icons.
- **R3:** Native `alert()` and `confirm()` calls are replaced with custom paper dialog modals.
- **R4:** Mobile view (< 900px) stacks image and dialogue using single grid layout.
