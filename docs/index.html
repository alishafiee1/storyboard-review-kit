Storyboard Review Kit

A free storyboard, prompt and voice-over review tool for AI-made videos and animations. Your scenario, image prompts, generated pictures and narration live in plain text files. You scroll through the whole story on one page, edit it in the browser and generate voice-over per speaker. No database, no build step, no account: just Python and a browser.

What you get

  • One scrolling review page: every picture is a page of a long list, its dialogue beside it. Scroll, or use the ‹ › buttons and ← → keys; a gallery lets you drag pictures into a new order. Works on phones too.
  • Everything about a picture sits under it: flag, notes and edit advice, image prompt, video prompt.
  • Picture-based projects: each picture owns its dialogue lines; move pictures or scenes and no file is renamed.
  • Versions: keep several generated images per shot (Flow 2K/4K) side by side and approve by stopping on one.
  • Text-to-speech per speaker and line (ElevenLabs, Gemini, Qwen and more through one OpenRouter key); only changed lines are rebuilt.
  • Automatic downloads: files from your Downloads folder that belong to the project are filed into the right folders for you.
  • Undo for every structural change (Ctrl+Z), and updates that never touch your project data.
  • Ready for AI assistants: a short built-in guide tells Claude, Codex or any coding agent how the project works.
  • Hand-over: subtitles (SRT), batch prompts for Google Flow, a Premiere timeline and a zip for your editor.

Quick start

Needs Python 3.9 or newer. Nothing else to install.

python -c "import urllib.request as u;exec(u.urlopen('https://raw.githubusercontent.com/alishafiee1/storyboard-review-kit/main/tools/update.py').read())" --new my-video
cd my-video
python tools/serve.py

Open http://127.0.0.1:8765/review.html (on Windows, double-click click-for-review.bat). To add the kit to an existing project, copy tools/update.py into it once and run python tools/update.py.

Questions

Is it really free? Yes, MIT license, personal and commercial use. Voice generation uses your own OpenRouter key and nothing is generated until you press a button.

Does it need the internet or an account? Only for voice generation and for updates. The review page itself runs locally.

Which video tools does it fit? Any AI image or video tool, built around Google Flow naming. It exports to Premiere and writes SRT subtitles.
