Storyboard Review Kit

A free, single-page storyboard and review tool for AI-made videos and animations. Your scenario, image prompts, generated pictures and narration live in plain text files; you review everything on one page, edit it in the browser and generate voice-over per speaker and scene.

  • One review page with scene images, dialogue, descriptions and prompts
  • Persian and English lines, speakers with colours and voices, right-to-left friendly
  • Text-to-speech per speaker and per scene (ElevenLabs, Gemini, Qwen and more) through one OpenRouter key
  • Stale flags when text or voice changes, rebuild only what changed
  • In-place updates that never touch your project data: python tools/update.py

Quick start

python -c "import urllib.request as u;exec(u.urlopen('https://raw.githubusercontent.com/alishafiee1/storyboard-review-kit/main/tools/update.py').read())" --new my-video
cd my-video
python tools/serve.py
