# اسکریپت‌های مخصوص این پروژه

> این فایل مال پروژهٔ توست؛ `python tools/update.py` هرگز دستش نمی‌زند. هوش مصنوعی قبل از هر کار این را می‌خواند و اگر برای کاری اسکریپتی اینجا معرفی شده باشد، همان را به‌جای دستور پیش‌فرض کیت می‌زند.

برای هر اسکریپت یک کارت بنویس (اگر چیزی نداری، همین فایل خالی بماند):

```
## اسم کار (مثلاً خروجی پریمیر)
- **جای‌گزین:** کدام دستور کیت را عوض می‌کند (مثلاً `tools/premiere_export.py`)
- **کی:** چه وقتی اجرا می‌شود
- **دستور:** `python tools/export_premiere.py --lang fa`
- **ورودی ← خروجی:** چه می‌خواند و کجا می‌نویسد
- **چک نهایی:** چطور بفهمیم درست بوده
```
