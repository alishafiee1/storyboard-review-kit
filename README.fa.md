# ابزار بازبینی استوری‌بورد (Storyboard Review Kit)

**یه ابزار رایگان و تک‌صفحه‌ای برای برنامه‌ریزی و بازبینی ویدئو و انیمیشن‌هایی که با هوش مصنوعی ساخته می‌شن.** سناریو، پرامپت تصویرها، عکس‌های ساخته‌شده و صدای گوینده همه توی فایل‌های متنی ساده‌ان؛ همه‌شون رو توی یه صفحه می‌بینی، همون‌جا ویرایش می‌کنی و صدای هر گوینده رو می‌سازی. بدون دیتابیس و نصب پیچیده: فقط Python و مرورگر.

[English](README.md) · [وب‌سایت](https://alishafiee1.github.io/storyboard-review-kit/) · لایسنس: MIT (رایگان)

## چه کار می‌کنه؟
- **صفحهٔ بازبینی:** هر صحنه با عکسش، دیالوگ‌ها، توضیح صحنه و پرامپت. تأیید، بازسازی، یادداشت.
- **پروژهٔ متنی ساده:** فقط `scenario/story.txt` و `prompts/prompts.txt`؛ با گیت هم راحت کار می‌کنه.
- **متن دوزبانه (فارسی و انگلیسی)** با گوینده‌های رنگی، لحن هر خط و راست‌به‌چپ.
- **ویرایش توی صفحه:** روی متن کلیک کن، تغییرش بده، Enter بزن. کلیک بیرون از کادر هم ذخیره می‌کنه.
- **ساخت صدا:** مدل و صدای هر گوینده یا صحنه رو انتخاب کن (ElevenLabs، Gemini، Qwen و ...) با یه کلید OpenRouter؛ نمونه‌ش رو گوش بده و فقط صحنه‌هایی که عوض شدن رو دوباره بساز.
- **پرامپت ویدیو و پخش ویدیو:** هر تصویر یه پرامپت «تصویر به ویدیو» هم داره (`prompts/video-prompts.txt`)؛ تصویر یا رفرنسی که ویدیو داره دکمهٔ ▶ می‌گیره.
- **دکمهٔ شناور پخش خودکار:** از آخرین خطی که روی «FA» یا «EN» ش کلیک کردی به بعد، به همون زبان می‌خونه؛ بدون کلیک از اول.
- **گوش دادن به هر خط:** هر دیالوگی که فایل صدا داشته باشه دو دکمهٔ کوچیک «🔊 FA» و «🔊 EN» می‌گیره تا فقط همون خط پخش بشه.
- **پرچم «کهنه»:** با عوض کردن متن یا صدا، صدا یا عکس اون صحنه کهنه علامت می‌خوره.
- **آپدیت بدون از دست رفتن کار:** دستور `python tools/update.py` فقط فایل‌های ابزار رو عوض می‌کنه؛ سناریو، پرامپت، عکس و صدای تو دست نمی‌خوره.

## شروع سریع
پیش‌نیاز: Python نسخهٔ ۳٫۹ به بالا (بدون نصب بستهٔ اضافه).

```bash
# ساخت پروژهٔ جدید از آخرین نسخه
python -c "import urllib.request as u;exec(u.urlopen('https://raw.githubusercontent.com/alishafiee1/storyboard-review-kit/main/tools/update.py').read())" --new my-video
cd my-video
python tools/serve.py        # ویندوز: دابل‌کلیک روی click-for-review.bat
```
بعد این آدرس رو باز کن: http://127.0.0.1:8765/review.html

## آپدیت پروژهٔ موجود
```bash
cd my-video
python tools/update.py          # فقط review.html و tools/*.py عوض می‌شن
python tools/update.py --check  # فقط می‌گه نسخهٔ جدیدتری هست یا نه
```
فایل‌های قدیمی قبل از جایگزینی توی `.engine-backup/` کپی می‌شن. اگه پروژه‌ت هنوز `update.py` نداره، یه بار فایل `tools/update.py` این مخزن رو توی پوشهٔ `tools/` پروژه کپی کن.

## تنظیم ساخت صدا (اختیاری)
کنار `review.html` فایل `.env` بساز با یه خط `OPENROUTER_API_KEY=...` (توی گیت نمی‌ره)، بعد توی تب «صدا و گوینده‌ها» دکمهٔ «رفرش لیست صداها» رو بزن. برای هر گوینده صدا و برای هر صحنه مدل انتخاب کن و با «بازسازی صدا» بساز. تا دکمه رو نزنی چیزی ساخته نمی‌شه و پولی خرج نمی‌شه.
