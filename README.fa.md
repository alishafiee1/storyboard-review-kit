# ابزار بازبینی استوری‌بورد (Storyboard Review Kit)

**یه ابزار رایگان و تک‌صفحه‌ای برای برنامه‌ریزی و بازبینی ویدئو و انیمیشن‌هایی که با هوش مصنوعی ساخته می‌شن.** سناریو، پرامپت تصویرها، عکس‌های ساخته‌شده و صدای گوینده همه توی فایل‌های متنی ساده‌ان؛ همه‌شون رو توی یه صفحه می‌بینی، همون‌جا ویرایش می‌کنی و صدای هر گوینده رو می‌سازی. بدون دیتابیس و نصب پیچیده: فقط Python و مرورگر.

[English](README.md) · [وب‌سایت](https://alishafiee1.github.io/storyboard-review-kit/) · [تغییرات](CHANGELOG.md) · لایسنس: MIT (رایگان)

## چه کار می‌کنه؟
- **یه صفحهٔ بازبینی قابل اسکرول:** هر تصویر یه «صفحه» از یه لیست بلنده (عکس یه طرف، دیالوگ‌هاش طرف دیگه). با اسکرول داستان رو می‌خونی، یا با دکمه‌های ‹ › و کلیدهای ← →. گالری همهٔ تصویرها هم داری و با کشیدن و رها کردن ترتیبشون رو عوض می‌کنی. روی موبایل هر صفحه یه تصویر با نوار پایین.
- **هر چی به یه تصویر مربوطه، زیر خودشه:** پرچم، یادداشت و توصیهٔ ادیت، پرامپت تصویر و پرامپت ویدیو.
- **پروژهٔ متنی ساده:** فقط `scenario/story.txt` و `prompts/prompts.txt` منبع اصلی‌ان؛ توی صفحه یا هر ادیتوری ویرایششون کن؛ با گیت هم راحته.
- **مدل تصویرمحور:** صحنه فقط یه خط نشونه‌ست؛ هر تصویر (`[IMG045]`) دیالوگ‌های خودش رو داره (`IMG045-1`، `IMG045-2`). جابه‌جایی تصویر یا صحنه هیچ فایلی رو تغییر اسم نمی‌ده.
- **متن دوزبانه (فارسی و انگلیسی)** با گوینده‌های رنگی، لحن هر خط و راست‌به‌چپ.
- **ساخت صدا:** مدل و صدای هر گوینده و هر خط رو انتخاب کن (ElevenLabs، Gemini، Qwen و ...) با یه کلید OpenRouter؛ چند نسخه صدا برای هر خط، همونی که آخر می‌ذاری نهاییه؛ فقط خط‌های عوض‌شده دوباره ساخته می‌شن.
- **نسخه‌ها:** چند عکس برای یه نما کنار هم می‌مونن (شناسهٔ تصادفی Flow، ۲K و ۴K)؛ نسخه‌ای که روش می‌ایستی تأییدشده‌ست.
- **دانلود خودکار:** وقتی سرور بازبینی بازه، پوشهٔ `Downloads` رو زیر نظر داره و فایل‌های Flow که مال همین پروژه‌ان رو خودش به `images/scenes/bNN/` یا `images/refs/` می‌بره (برای خاموش‌کردن: `"watch_downloads": false` توی `kit-config.json`). فایل‌های متفرقه می‌رن `inbox/`.
- **برگردان (Undo):** تغییرهای ساختاری (افزودن، حذف، جابه‌جایی) توی `.kit/history` عکس می‌گیرن؛ با **Ctrl+Z** یا آیکون برگردان نوار بالا پس می‌گیری.
- **پرامپت ویدیو**، **توصیهٔ ادیت** (`fx:`)، **زیرنویس** (`fa.srt` و `en.srt` با زمان‌بندی از روی صداها) و **پرامپت دسته** برای Flow (`python tools/batch.py b05`).
- **تحویل به ادیتور:** `python tools/premiere_export.py` تایم‌لاین پریمیر می‌سازه و `python tools/pack.py` پروژه رو برای ادیتور زیپ می‌کنه.
- **آپدیت امن:** `python tools/update.py` فقط فایل‌های ابزار (و راهنمای هوش مصنوعی) رو عوض می‌کنه؛ سناریو، پرامپت، عکس و صدای تو دست نمی‌خوره.

## شروع سریع
پیش‌نیاز: Python نسخهٔ ۳٫۹ به بالا (بدون نصب بستهٔ اضافه).

```bash
# ساخت پروژهٔ جدید از آخرین نسخه
python -c "import urllib.request as u;exec(u.urlopen('https://raw.githubusercontent.com/alishafiee1/storyboard-review-kit/main/tools/update.py').read())" --new my-video
cd my-video
python tools/serve.py        # ویندوز: دابل‌کلیک روی click-for-review.bat
```
بعد این آدرس رو باز کن: http://127.0.0.1:8765/review.html

## اضافه‌کردن به پروژهٔ موجود
یه بار فایل `tools/update.py` این مخزن رو توی پوشهٔ `tools/` پروژه کپی کن و همون‌جا اجراش کن:
```bash
cd my-video
python tools/update.py          # review.html، tools/ و راهنمای هوش مصنوعی توی skills/ عوض می‌شن
python tools/update.py --check  # فقط می‌گه نسخهٔ جدیدتری هست یا نه
```
فایل‌های قدیمی قبل از جایگزینی توی `.engine-backup/` کپی می‌شن. اگه پروژه‌ت قدیمی باشه، آپدیت‌کننده بهت می‌گه: اول `python tools/migrate.py` (فقط گزارش، چیزی عوض نمی‌شه) و اگه گزارش خوب بود `python tools/migrate.py --apply` (پشتیبان می‌گیره و با `--undo` برمی‌گرده).

## کار با دستیار هوش مصنوعی
هر پروژه یه راهنمای کوتاه برای دستیارهای برنامه‌نویسی داره: `skills/how-to-write-prompts-for-flow.md` (قانون‌ها، قالب `story.txt`، اسم‌گذاری فایل‌ها و حلقهٔ بازبینی) و یه `CLAUDE.md` که به اون اشاره می‌کنه و قانون‌های مخصوص پروژهٔ خودت رو نگه می‌داره (سبک، لحن راوی، شخصیت‌ها). راهنما جزو موتوره و با `update.py` همیشه به‌روز می‌مونه. به دستیارت بگو اول `CLAUDE.md` رو بخونه.

## تنظیم ساخت صدا (اختیاری)
کنار `review.html` فایل `.env` بساز با یه خط `OPENROUTER_API_KEY=...` (توی گیت نمی‌ره). از منوی بالا راست «صداها و گوینده‌ها» رو باز کن، لیست صداها رو رفرش کن، برای هر گوینده صدا انتخاب کن و بعد صدای یه خط یا یه صحنه رو بساز. تا دکمه رو نزنی چیزی ساخته نمی‌شه و پولی خرج نمی‌شه.

## ساختار پوشه‌ها
| مسیر | چیه |
|---|---|
| `review.html`، `click-for-review.bat`، `tools/`، `skills/how-to-write-prompts-for-flow.md` | خود ابزار (با `update.py` به‌روز می‌شه) |
| `scenario/story.txt` | صحنه‌ها، دیالوگ‌ها، گوینده‌ها، یادداشت‌ها و پرچم‌ها |
| `prompts/prompts.txt` و `prompts/video-prompts.txt` | یه پرامپت کامل تصویر و ویدیو برای هر تصویر |
| `images/scenes/bNN/` و `images/refs/<KIND>/` | تصویرها (۱۰ تا توی هر پوشهٔ دسته) و رفرنس‌ها |
| `inbox/` | فایل‌های متفرقه که هوش مصنوعی مرتب می‌کنه |
| `audio/fa`، `audio/en`، `voices/` | صداها، مدل‌ها و لحن‌ها |
| `videos/clips/`، `subtitles/`، `premiere/` | کلیپ‌ها، زیرنویس، تحویل به ادیتور |
| `.kit/` | تاریخچهٔ برگردان و لاگ ورود فایل‌ها (دست نزن) |

## توسعه
نقشهٔ کد، قالب فایل‌ها، API و چک‌لیست قابلیت جدید توی [ARCHITECTURE.md](ARCHITECTURE.md) هست. تست واحد: `python -m unittest discover -s tools/tests -p "test_*.py"`. تست مرورگر: `pip install playwright` و بعد `python tools/tests/run.py`.
